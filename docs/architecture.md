# Архитектура

GeoRomb состоит из трёх программ и общего кода:

```
                 ┌───────────────────────────── телефон ─────────────────────────────┐
                 │  Android (Capacitor)                                               │
                 │  ┌──────────────────────── app/ ───────────────────────────────┐   │
                 │  │ features/  экраны ──▶ model/  расчёты ──▶ render/  SVG-схема │   │
                 │  │     │                                                       │   │
                 │  │     └──▶ storage.ts  localStorage (iwd.*)                   │   │
                 │  └───────────────▲─────────────────────────────────────────────┘   │
                 └──────────────────┼─────────────────────────────────────────────────┘
                                    │ скачивает revoked.json (подписан)
  ┌──────── backend/ ────────┐      │                      ┌──────── server/ ──────────┐
  │ CLI лицензий (ваш ПК)    │──────┴──▶ GitHub Pages      │ API для WhatsApp-бота     │
  │ подписывает коды и       │   bakhtiyararzimetov/GeoRomb│ JSON проекта → PDF        │
  │ revoked.json             │                             │ (тот же model/ и render/) │
  └──────────────────────────┘                             └───────────────────────────┘
                     shared/license.ts — формат кодов и подписи (общий для app и backend)
```

## app/ — мобильное приложение

TypeScript без фреймворка. Vite собирает его в `app/dist`, Capacitor упаковывает в APK.

| Папка | Что внутри | Правило |
|---|---|---|
| `src/types.ts` | модель данных: `Project`, `WinElement`, `TreeNode`, `Layout` | формат совпадает с сохранённым у пользователей — не переименовывать |
| `src/state.ts` | общее изменяемое состояние `S` | |
| `src/storage.ts` | чтение и запись `localStorage` | |
| `src/data/` | справочники: цвета, стёкла, профильные системы ПВХ и алюминия | |
| `src/model/` | расчёты: дерево делений, раскладка, размеры, история, смета, раскрой профиля и стекла | **без DOM** — используется и сервером |
| `src/render/` | SVG-схема окна, векторы фурнитуры, чертёж для PDF | без DOM |
| `src/features/` | экраны: проекты, элемент, 3D, каталог, раскрой, склад, цены, бэкап, PDF, лицензия | |
| `src/platform/` | Capacitor, «Поделиться» | |
| `src/ui/` | DOM-помощники и общие диалоги | |
| `src/main.ts` | запуск и реестр обработчиков для `onclick` в разметке | |

**Окно — это дерево.** Элемент (`WinElement`) хранит корень `root: TreeNode`. Ветка (`branch`) делит область импостами вертикально (`dir: 'v'`) или горизонтально (`'h'`). Лист (`leaf`) — это стекло, панель или створка (`opening`), а внутри створки может быть ещё одно деление (`inner`). По дереву `model/layout.ts → computeLayout` считает прямоугольники рамы, импостов, створок и стёкол в мм. Из этой раскладки берутся схема (`render/svg.ts`), смета (`model/pricing.ts`), раскрой (`model/cutOptimizer.ts`, `model/sheetCut.ts`) и PDF.

**PDF без библиотек.** Страницы A4 рисуются на canvas (150 dpi), чертёж — тем же `buildSvg`, в PDF кладутся JPEG-картинки (`features/pdf.ts`). Язык PDF: русский, узбекский или кыргызский (`features/pdfI18n.ts`).

## server/ — API для WhatsApp-бота

Node.js + `node:http`, без фреймворка. Использует `app/src/model` и `app/src/render` напрямую, поэтому чертёж в PDF такой же, как в приложении. Страница собирается в SVG, растеризуется [resvg](https://github.com/yisibl/resvg-js) со шрифтом DejaVu Sans и вкладывается в PDF через [pdf-lib](https://pdf-lib.js.org/). Отрисовка идёт в `worker_threads`: не больше 2 одновременно, очередь 8, при перегрузке ответ 503.

Подробно: [api.md](api.md).

## backend/ — лицензии

CLI на Node.js. Хранит закрытый ключ и базу клиентов локально, выдаёт коды активации и собирает подписанный `revoked.json`. Подробно: [licensing.md](licensing.md).

## shared/license.ts

Формат ID устройства, кодов активации и файла `revoked.json`, подпись и проверка ECDSA P-256 (WebCrypto). Приложение содержит только открытый ключ.

## Тесты и CI

- `server/test/` — тесты на `node:test`: проверка JSON, отрисовка, HTTP-коды, работа под нагрузкой.
- [`.github/workflows/ci.yml`](../.github/workflows/ci.yml) на каждый push и Pull Request запускает `npm ci`, `typecheck`, `test` и `build`.
