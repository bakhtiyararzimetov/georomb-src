# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## Не выпущено (1.3)

### Добавлено
- **Данные переживают удаление приложения.**
  - ID устройства теперь берётся из системного ANDROID_ID через `@capacitor/device`. После удаления и повторной установки APK с той же подписью ID остаётся прежним, и активация из списка возвращается кнопкой «Проверить». Уже сохранённый ID при обновлении не меняется.
  - Автокопия проектов, цен, склада, настроек и кода активации в `Документы/GeoRomb/georomb-backup-<дата>-<метка>.json`. Копия пишется через 3 с после изменений и при сворачивании, хранятся последние 7 дней.
  - Восстановление: «Настройки → Импорт проектов» или кнопка «Восстановить из копии» на экране активации. Код активации из копии принимается, только если подходит этому устройству. Проекты, которые уже есть, не дублируются.
  - Код активации попадает только в полную копию, а не в выборочный экспорт, который отправляют клиентам.
  - На Android 10 и ниже разрешение на память запрашивается один раз после разблокировки. При отказе автокопия выключается.
- API для WhatsApp-бота (`server/`): `POST /api/generate-window-pdf` принимает JSON проекта и сразу возвращает PDF с чертежами, а с `?format=json` — координаты. Подробнее: [docs/api.md](docs/api.md).
- Структура репозитория: документация в `docs/`, `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, CI на GitHub Actions, шаблоны Issue и Pull Request.

### Добавлено (API)
- Адрес `/api/v1/generate-window-pdf`; старый `/api/generate-window-pdf` работает как раньше.
- Ключ доступа (`API_KEYS`, заголовок `X-API-Key` или `Authorization: Bearer`) и лимит запросов в минуту (`RATE_LIMIT`, по умолчанию 60): ответы `401 unauthorized` и `429 rate_limited` с `Retry-After`.
- `X-Request-Id` в каждом ответе и в логе, `requestId` в теле ошибки; строка лога на каждый запрос.
- `?lang=uz|ky` — подписи PDF на узбекском и кыргызском.
- Цвет профиля и стекла: `GET /api/v1/catalog` со всеми кодами, строка «Цвет профиля» в таблице PDF, `defaultColor` / `defaultGlass` проекта применяются к окнам. Неизвестный код — `400` со списком, а не молча белый.
- Подоконник у окна (`sill: true`) без длины — ширина окна + 40 мм и полка 20 см, как в приложении (было 0 м). Длинные значения в таблице PDF переносятся на вторую строку, а не обрезаются.
- `?format=georomb` — файл `<имя проекта>.json` для «Импорт проектов» в приложении: заказ из бота открывается в приложении со сметой и раскроем.
- `GET /docs` — документация в Swagger UI (Authorize, Try it out, пример проекта); `GET /openapi.json` — описание API (OpenAPI 3.1), адрес сервера — из `PUBLIC_URL`.
- `npm run api-key` — новый ключ вида `gr_…`.
- Выкладка на Render бесплатно: `render.yaml` (Blueprint), самопинг `KEEP_ALIVE=1`, чтобы сервер не засыпал, настройки `PDF_CONCURRENCY` и `PDF_TIMEOUT` для слабого сервера.
- Выкладка в Google Cloud Run: `scripts/deploy-cloudrun.sh` и `.gcloudignore` (в Google уходят только файлы сервера).
- `Dockerfile`: образ только с сервером, проверка `/health`, при остановке начатые PDF дорисовываются.

### Исправлено (API)
- Размер в таблице PDF («1500 × 1200 мм») больше не налезает на колонку «Створки».

### Изменено (вид)
- Иконка и заставка приложения — логотип «GeoR◆mb» (синие буквы, жёлтый ромб, белый фон); `npm run icons` рисует все размеры из вектора.

### Добавлено (лицензия)
- Перевод даты на телефоне назад больше чем на сутки больше не продлевает лицензию: приложение просит поставить дату по сети и нажать «Проверить».
- Раз в 30 дней нужна проверка лицензии через интернет (за 5 дней — предупреждение). Без этого отозванный клиент мог бы работать бесконечно, просто не выходя в сеть.

### Добавлено (смета)
- Штапик и уплотнитель — цена за метр (уплотнитель: с двух сторон каждого стекла и по периметру створок).
- Стекло по видам — своя цена за м² у каждого стекла каталога; без цены — общая.
- Доплата за цвет профиля: цветной и ламинация — % к профилю, отдельной строкой; белый — без доплаты.
- Работы и доставка: монтаж и демонтаж (за м² окон), откосы (за метр), доставка (за заказ) — включаются галочками в смете проекта.
- Скидка (сумма или %) и аванс в смете и PDF: Всего → Скидка → Налог → Итого → Аванс → Остаток к оплате.
- Все новые цены по умолчанию 0 — старые сметы не меняются.

### Изменено (раскрой и склад — правила romchi)
- Пропил только между деталями: 4 × 1496 мм с пропилом 5 — один хлыст 6000 (было два).
- Склад подбирается до раскроя, как в romchi: детали от длинных к коротким, каждая — туда, где останется меньше всего; без правила подрезки (настройка «Подрезка остатка» убрана).
- Порядок вариантов как в romchi: хлысты → % всех остатков (и деловых) → со склада → новых обрезков → их длина.
- Без лимита времени: результат одинаков на любом телефоне; группы больше 300 деталей — упрощённый расчёт.
- Длины деталей без дробной части, как в romchi.
- Хлыст по умолчанию: ПВХ — 6500 мм, алюминий — 6000 мм (старые настройки с ПВХ 6000 переводятся на 6500 один раз).

### Исправлено
- Где лежит автокопия, видно сразу: под «Восстановить из копии» — подсказка «Documents → GeoRomb, самый новый файл»; папка везде названа так, как её показывает телефон (Documents). Папку в корне памяти Android 11+ без опасного разрешения «Доступ ко всем файлам» создать не даёт.
- Новая установка начинается с пустого списка: демо-проекты «Проект 1», «Проект 2», «Пример проекта» после переустановки выглядели как вернувшиеся удалённые проекты. Примеры — «Настройки → Добавить примеры»; в пустом списке — подсказка про импорт из «Документы/GeoRomb».
- Отдельный подоконник в смете считается как подоконник (по ширине полки), без рамы, стекла и площади окна.
- Дробный пропил (например, 2,5 мм) больше не ломает раскрой: остатки склада снова подбираются, точные алгоритмы не хуже простых.
- Одна повреждённая запись в памяти больше не заменяет все проекты демо-проектами; повреждённые данные сохраняются в `iwd.projects.corrupt.v1`. Проект без имени не ломает главный экран.
- Если память телефона заполнена, приложение предупреждает, а импорт не пишет «Импортировано».
- Восстановление из копии не теряет окна с большим числом полей (до 100 в ряду), переносы строк в описании, кавычки и `&` в названиях.
- Форма элемента не сохраняет невозможный размер, а правка размера — обычный шаг «Отменить» / «Вернуть». Как и на схеме, меняется только крайняя часть: по ширине — правая, по высоте — верхняя; заданные размеры остальных частей сохраняются.
- Размер с запятой («1500,5») читается как 1500,5; количество 0 — 0 шт в смете, раскрое и списке стёкол.
- CLI лицензий: опечатка или пустое значение в `--days` (в том числе у `extend`) — ошибка, а не бессрочная лицензия.
- Отдельный подоконник в сводке и PDF подписан «Подоконник» (длина × ширина полки), без строк окна. Глубина по умолчанию — 200 мм везде.
- Смета отходов группирует цвета так же, как экран раскроя. Дробное количество (0,4) в раскрое — хотя бы одна деталь.
- Импорт, упёршийся в заполненную память, возвращает всё как было. Восстановленный проект без номера не получает чужой номер. Сохраняется первая повреждённая копия данных.
- Перетаскивание размера понимает запятую в старых данных.

### Изменено
- Чертёж для PDF вынесен в `app/src/render/drawingSvg.ts`, чтобы им мог пользоваться сервер. Поведение приложения не изменилось.

## 1.2 — 2026-10-01

### Добавлено
- Москитная сетка в форме элемента: размеры по створкам, цена за м², раскрой профиля сетки.
- Армирование ПВХ: длины по раме, импостам и створкам, отдельная группа раскроя и цена за метр.
- Учёт отходов профиля в цене: без отходов, процентом, по полной длине или по минимальным размерам.
- Список стёкол и сеток для стекольщика, раскрой стекла на листах, PDF.
- PDF на русском, узбекском и кыргызском; в PDF проекта можно включать и выключать цены и размеры.
- Раскрой: точный перебор, пометка «лимит времени», список групп, которые не удалось рассчитать.

Ранние версии выпускались до ведения журнала.
