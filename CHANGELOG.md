# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## Не выпущено (1.3)

### Добавлено
- **Данные переживают удаление приложения.**
  - ID устройства теперь берётся из системного ANDROID_ID через `@capacitor/device`. После удаления и повторной установки APK с той же подписью ID остаётся прежним, и активация из списка возвращается кнопкой «Проверить». Уже сохранённый ID при обновлении не меняется.
  - Автокопия проектов, цен, склада, настроек и кода активации в `Документы/GeoRomb/georomb-backup-<дата>-<метка>.json`. Копия пишется через 3 с после изменений и при сворачивании, хранятся последние 7 дней.
  - Восстановление: «Настройки → Импорт проектов» и выбрать файл копии. Код активации из копии принимается, только если подходит этому устройству.
- API для WhatsApp-бота (`server/`): `POST /api/generate-window-pdf` принимает JSON проекта и сразу возвращает PDF с чертежами, а с `?format=json` — координаты. Подробнее: [docs/api.md](docs/api.md).
- Структура репозитория: документация в `docs/`, `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, CI на GitHub Actions, шаблоны Issue и Pull Request.

### Изменено
- Чертёж для PDF вынесен в `app/src/render/drawingSvg.ts`, чтобы им мог пользоваться сервер. Поведение приложения не изменилось.

## 1.2 — 2026-10-01

### Добавлено
- Москитная сетка в форме элемента: размеры по створкам, цена за м², раскрой профиля сетки.
- Армирование ПВХ: длины по раме, импостам и створкам, отдельная группа раскроя и цена за метр.
- Учёт отходов профиля в цене: без отходов, процентом, по полной длине или по минимальным размерам.
- Список стёкол и сеток для стекольщика, раскрой стекла на листах, PDF.
- PDF на русском, узбекском и кыргызском; в PDF проекта можно включать и выключать цены и размеры.
- Раскрой: точный перебор, пометка «лимит времени», список групп, которые не удалось рассчитать.

Ранние версии выпускались до ведения журнала.
