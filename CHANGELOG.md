# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## Не выпущено (1.3)

### Добавлено
- **Данные переживают удаление приложения.**
  - ID устройства теперь берётся из системного ANDROID_ID через `@capacitor/device`. После удаления и повторной установки APK с той же подписью ID остаётся прежним, и активация из списка возвращается кнопкой «Проверить». Уже сохранённый ID при обновлении не меняется.
  - Автокопия проектов, цен, склада, настроек и кода активации в `Документы/GeoRomb/georomb-backup-<дата>-<метка>.json`. Копия пишется через 3 с после изменений и при сворачивании, хранятся последние 7 дней.
  - Восстановление: «Настройки → Импорт проектов» или кнопка «Восстановить из копии» на экране активации. Код активации из копии принимается, только если подходит этому устройству. Проекты, которые уже есть, не дублируются.
  - Код активации попадает только в полную копию, а не в выборочный экспорт, который отправляют клиентам.
  - На Android 10 и ниже разрешение на память запрашивается один раз после разблокировки. При отказе автокопия выключается.
- API для WhatsApp-бота (`server/`): `POST /api/generate-window-pdf` принимает JSON проекта и сразу возвращает PDF с чертежами, а с `?format=json` — координаты. Подробнее: [docs/api.md](docs/api.md).
- Структура репозитория: документация в `docs/`, `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, CI на GitHub Actions, шаблоны Issue и Pull Request.

### Исправлено
- Отдельный подоконник в смете считается как подоконник (по ширине полки), без рамы, стекла и площади окна.
- Дробный пропил (например, 2,5 мм) больше не ломает раскрой: остатки склада снова подбираются, точные алгоритмы не хуже простых.
- Одна повреждённая запись в памяти больше не заменяет все проекты демо-проектами; повреждённые данные сохраняются в `iwd.projects.corrupt.v1`. Проект без имени не ломает главный экран.
- Если память телефона заполнена, приложение предупреждает, а импорт не пишет «Импортировано».
- Восстановление из копии не теряет окна с большим числом полей (до 100 в ряду), переносы строк в описании, кавычки и `&` в названиях.
- Форма элемента не сохраняет невозможный размер, а правка размера — обычный шаг «Отменить» / «Вернуть».
- Размер с запятой («1500,5») читается как 1500,5; количество 0 — 0 шт в смете, раскрое и списке стёкол.
- CLI лицензий: опечатка или пустое значение в `--days` (в том числе у `extend`) — ошибка, а не бессрочная лицензия.
- Отдельный подоконник в сводке и PDF подписан «Подоконник» (длина × ширина полки), без строк окна. Глубина по умолчанию — 200 мм везде.
- Смета отходов группирует цвета так же, как экран раскроя. Дробное количество (0,4) в раскрое — хотя бы одна деталь.
- Импорт, упёршийся в заполненную память, возвращает всё как было. Восстановленный проект без номера не получает чужой номер. Сохраняется первая повреждённая копия данных.
- Перетаскивание размера понимает запятую в старых данных.

### Изменено
- Чертёж для PDF вынесен в `app/src/render/drawingSvg.ts`, чтобы им мог пользоваться сервер. Поведение приложения не изменилось.

## 1.2 — 2026-10-01

### Добавлено
- Москитная сетка в форме элемента: размеры по створкам, цена за м², раскрой профиля сетки.
- Армирование ПВХ: длины по раме, импостам и створкам, отдельная группа раскроя и цена за метр.
- Учёт отходов профиля в цене: без отходов, процентом, по полной длине или по минимальным размерам.
- Список стёкол и сеток для стекольщика, раскрой стекла на листах, PDF.
- PDF на русском, узбекском и кыргызском; в PDF проекта можно включать и выключать цены и размеры.
- Раскрой: точный перебор, пометка «лимит времени», список групп, которые не удалось рассчитать.

Ранние версии выпускались до ведения журнала.
